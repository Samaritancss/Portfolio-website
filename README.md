📌 Overview
This is my personal portfolio website—a digital home for my work as a frontend developer. It features a clean, minimal design with a focus on typography and user experience. The site highlights my projects and technical skills, and provides an easy way for recruiters and collaborators to get in touch.

✨ Features
Fully Responsive – Optimized for desktop, tablet, and mobile devices

Dark/Light Mode – Toggle between themes for comfortable viewing

Project Showcase – Clean grid layout displaying my best work

Interactive UI – Smooth animations and micro-interactions

Contact Form – Direct messaging functionality

Performance Optimized – Fast load times and Lighthouse scores

🛠️ Tech Stack
